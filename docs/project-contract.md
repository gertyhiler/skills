# Project contract

The [canonical project documentation contract](../skills/setup-workflows/references/project-contract.md)
lives inside `setup-workflows` so that the skill remains independently installable.
Use it to author exact `agents/project-docs.json` requirements and to configure a
consumer. The [document templates](../skills/setup-workflows/references/section-seeds.md)
describe the owner and required content for each standard document. Projects
own the decisions, commands and authorization those documents record.
